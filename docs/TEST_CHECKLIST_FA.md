# چک‌لیست آزمون نسخهٔ ۰.۳.۰

هیچ‌کدام از آزمون‌های زیر در محیط ساخت سورس روی دستگاه واقعی اجرا نشده‌اند.

## ویندوز
- [ ] ساخت x64 در GitHub Actions با .NET 8 و اجرای EXE روی Windows 10/11.
- [ ] شناسایی TCP/IPv4 مرورگر و تطبیق PID با Task Manager.
- [ ] برقراری/قطع اتصال و مشاهدهٔ تغییر پس از تازه‌سازی.
- [ ] اتصالات LISTEN و نام پردازش‌های حفاظت‌شده بدون کرش برنامه.
- [ ] خروجی UTF-8 CSV و جستجوی چند فیلد.
- [ ] تغییر رابط شبکه، خاموش‌شدن کارت، Reset counter، sleep و resume.
- [ ] بررسی عدم دوباره‌شماری در اتصال هم‌زمان به VPN و Wi-Fi.

## اندروید
- [ ] ساخت APK با Android Studio/CI و نصب روی API 26، 33، 35.
- [ ] تأیید اعطای Usage Access و واکنش به لغو مجوز.
- [ ] برداشت اول بدون اختلاف؛ برداشت دوم با اختلاف غیرمنفی.
- [ ] عبور ترافیک آزمایشی از مرز ۱۰۰ MiB و ظاهرشدن هشدار در صفحه.
- [ ] نیمه‌شب و تغییر منطقه زمانی (بازهٔ جدید نباید با روز گذشته مقایسه شود).
- [ ] ذخیرهٔ نسخهٔ قبلی و ارتقا با حفظ داده‌ها.
- [ ] بررسی رفتار UID مشترک، VPN و برنامه‌های حذف‌شده.
- [ ] پاک‌سازی ۳۰روزه، خروجی CSV و اندازهٔ SQLite.

## موارد اختصاصی ۰.۴.۰ (هنوز روی دستگاه واقعی تأیید نشده)
- [ ] ارتقا روی دستگاهی با دیتابیس نسخهٔ ۰.۳ بدون ازدست‌رفتن سابقه.
- [ ] فعال‌سازی/غیرفعال‌سازی WorkManager، بسته‌بودن برنامه، ری‌استارت، Doze و حالت صرفه‌جویی باتری.
- [ ] رد مجوز Usage Access بعد از فعال‌سازی ثبت دوره‌ای و کنترل توقف امن برداشت.
- [ ] رد مجوز اعلان اندروید ۱۳+ بدون مختل‌شدن ثبت دوره‌ای.
- [ ] آزمون آستانه‌های ۱۰۰، ۵۰۰ و ۱۰۰۰ MiB و عدم ارسال هشدار هنگام برداشت اولیهٔ روز.
- [ ] تغییر روز محلی/ساعت تابستانی/UID مشترک و بررسی اختلاف آمار.
- [ ] ویندوز: فعال‌سازی و خاموش‌کردن خودکارسازی در پنجرهٔ ارتباطات؛ اطمینان از توقف بعد از بستن پنجره.
- [ ] ویندوز: بررسی فرمت CSV، پاک‌سازی هفت‌روزه و مصرف دیسک در روزهای پرترافیک.
