# تغییرات

## 0.6.0-rc1
- تأمین یک مسیر واقعی برای کنترل کیفیت با آزمون‌های سورس و Android lint در CI.
- اصلاح انتساب نمونه‌های ترافیک تجمیعی ویندوز به روز درست در زمان تغییر روز.
- کنترل اندازهٔ بافر جدول TCP و کاهش خطر گزارش CSV مخرب.
- اصلاح احتمال برخورد زمان برداشت‌های اندروید هنگام ثبت در SQLite.
- اجرای صادرات CSV اندروید خارج از thread رابط کاربری.
- نگه‌داشتن شناسهٔ اپ اندروید و schema داده‌های نسخهٔ پیشین.
- شفاف‌سازی وضعیت نامزد انتشار و موارد آزمایش‌نشده.

## 0.5.0
- تجمیع نمونه‌های ترافیک ویندوز و کنترل هشدارهای تکراری اندروید.
