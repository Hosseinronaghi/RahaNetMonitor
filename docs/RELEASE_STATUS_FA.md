# وضعیت انتشار نسخهٔ ۰.۶.۰-rc1

**طبقه‌بندی: نامزد انتشار سورس، نه نسخهٔ پایدار (GA).**

## اصلاحات انجام‌شده و قابل تأیید از سورس
- حفظ package/application ID اندروید و schema دیتابیس (نسخهٔ ۱).
- اصلاح زمان‌های برخوردی برای برداشت‌های SQLite در تراکنش.
- انتقال گزارش CSV اندروید به Dispatchers.IO.
- اصلاح ثبت ترافیک تجمیعی ویندوز در مرز تغییر روز و هنگام بسته‌شدن.
- بررسی محدودیت اندازه و شمارش ردیف‌های TCP ویندوز پیش از پیمایش بافر.
- کاهش خطر CSV formula injection در خروجی اتصالات ویندوز.
- افزودن آزمون‌های یکپارچگی سورس، Android lint و گیت CI برای دو پلتفرم.

## آزمون‌هایی که در این محیط انجام شده
- آزمون Python برای یکپارچگی سورس/Manifest و سازگاری شناسهٔ برنامه.
- اعتبارسنجی محتوای ZIP و بررسی فایل‌های ساخت.

## آزمون‌هایی که هنوز انجام نشده
- کامپایل واقعی .NET / Android، lint اندروید در CI، اجرای EXE و APK.
- آزمون migration با دیتابیس واقعی از نسخهٔ قبلی و restore پس از خاموش‌شدن ناگهانی.
- دقت‌سنجی با بار واقعی / حالت خواب / چندشبکه‌ای / VPN.
- امنیت اجرا با داده‌های غیرقابل اعتماد، بررسی حافظه و دوام باتری.

## شرط ارتقا به نسخهٔ پایدار
موفقیت ساخت CI، تست عملی روی Windows 10/11 و Android 10–17، تست عدم شکست/رگرسیون و دقت ثبت حجم. **تاکنون برآورده‌شدن این شروط تأیید نشده است.**
